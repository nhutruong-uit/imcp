# Project report

The report itself is written in **Vietnamese** (it is the course deliverable for IE103). This README describes how it
is produced.

- **`IE103_Group1_Report.pdf`** - the PDF exported from Word (table of contents and page numbers up to date),
  to be submitted/sent to the instructor.
- **`IE103_Group1_Report.docx`** - the report (formatted with the group's UIT report template). The committed file is
  the version saved by Word during the PDF export (table of contents, lists of figures/tables and page numbers already
  filled in), so Word opens it without asking to update fields. A docx freshly generated by `build_report.py` still
  asks: answer **Yes** (or press `Ctrl+A`, then `F9`) so Word rebuilds those lists, or run `tools/export_pdf.sh`.

## Regenerating the report after changing the content

The report is generated by a script so that it always matches the source code and the database:

```bash
pip3 install python-docx
# 1. real data from a freshly initialized database (test_all re-creates it), 2. docx, 3. PDF with Word, 4. checks
SQL_PASSWORD="$(docker exec imcp-mssql printenv MSSQL_SA_PASSWORD)" python3 docs/report/tools/export_data.py --docker imcp-mssql
python3 docs/report/build_report.py
./docs/report/tools/export_pdf.sh
swift docs/report/tools/check_pdf.swift check docs/report/IE103_Group1_Report.pdf
```
With Claude Code, `/imcp-update-report` runs the whole pipeline (screenshots and diagrams included).

| Component | Location |
|---|---|
| Content of each chapter | `content/chapter*.py` (each member edits the chapter they own) |
| Cover page, checklist, assignment table | `content/front_matter.py`, `content/common.py` |
| SQL code in the code boxes | extracted automatically from `database/*.sql` |
| Data dictionary | `data/schema.json` (exported from the real database) |
| Query and test results | `data/query_results.json`, `data/database_tests.txt` |
| Diagrams (ERD, CD, use case, DFD, ...) | sources `diagrams/*.dot` → `images/diagrams/*.png` |
| Application screenshots | `images/screens/` (generated by `tools/qlttta_screenshots` with the Vietnamese UI, see [../SETUP.md](../SETUP.md)) |
| Formatting template | `template/uit_report_template.docx` |

Redraw the diagrams after editing a `.dot` file (requires `brew install graphviz`):
```bash
cd docs/report/diagrams && for f in *.dot; do dot -Tpng "$f" -o "../images/diagrams/${f%.dot}.png"; done
```

> Never edit the document directly in Word: the next regeneration overwrites your changes. Edit the content in
> `content/` and regenerate (`.claude/rules/05-report.md`).
