## Done well

- The database carries the rules: cross-column CHECKs, set-based triggers that recompute derived values from scratch,
  receipts and the audit log protected twice (INSTEAD OF trigger + DENY), safe dynamic SQL with `QUOTENAME`.
- Time is handled once: UTC instants, center dates through `fn_Today`, sargable UTC ranges, checked by T31/T32.
- Conventions are tests, not wishes: `tst_conventions`, `tst_i18n`, T28-T30/T32 and `check_changes`.
- Clean Architecture holds: fake repositories, `Result<T>`, all SQL in infrastructure, i18n catalogs keyed by codes.
- The headers explain every object for the oral defense, and the docs follow the code closely.
