QLTTTA - QUẢN LÝ TRUNG TÂM TIẾNG ANH (bản Windows 10/11, 64-bit)
=================================================================

1. Cài đặt
   - Bản setup: chạy QLTTTA-x.y.z-windows-x64-setup.exe (không cần quyền Administrator).
   - Bản portable: giải nén file .zip, chạy QLTTTA.exe.
   - Nếu Windows báo "Windows protected your PC" (SmartScreen): bấm "More info" > "Run anyway"
     (ứng dụng sinh viên chưa ký số thương mại).

2. Cơ sở dữ liệu
   - Cần SQL Server 2012 trở lên (Express/Developer đều được) đã khởi tạo CSDL QLTTTA
     bằng các script trong thư mục database/ của mã nguồn (chạy scripts\db_init.ps1
     hoặc mở lần lượt 00 -> 07 trong SSMS).

3. Đăng nhập
   - Màn hình đăng nhập > "Cấu hình máy chủ":
       Máy chủ: localhost (hoặc TEN-MAY\SQLEXPRESS, hoặc 192.168.1.10,1433)
       CSDL   : QLTTTA
   - Tài khoản demo: xem docs/SETUP.md.

4. Driver kết nối
   - Ứng dụng tự dùng "ODBC Driver 18/17 for SQL Server" nếu máy đã có (thường có sẵn khi cài
     SSMS), nếu không sẽ dùng driver "SQL Server" có sẵn của Windows.
   - Nếu báo lỗi chứng chỉ/TLS: cài "Microsoft ODBC Driver 18 for SQL Server" từ trang Microsoft
     và bật "Tin cậy chứng chỉ máy chủ" trong phần cấu hình.
